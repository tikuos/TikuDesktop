TikuImage

An image and camera-snapshot viewer using TikuDesktop's native controls. Choose Applications > TikuImage. Startup preferences can launch an empty viewer automatically; images and watches are not restored.

Opening an image

Choose Open or press Ctrl+O and select a local image. PNG, baseline JPEG and uncompressed 24/32-bit BMP are supported. The format is detected from the file contents, not just the filename. Image files opened in Tracker use TikuImage by default. PNG (.png), JPEG (.jpg/.jpeg) and BMP (.bmp) associations also recognize uppercase extensions. TikuImage appears in Open With and the Info window's Opens with choices. An explicitly chosen alternative handler takes precedence. A failed load keeps the previous image and explains why in the status strip; no separate error dialog interrupts you.

Standalone TikuTracker forwards image opens to the running TikuDesktop; start the desktop first. It does not start another desktop automatically. Open one image at a time; multi-file Open With requests are refused explicitly.

Inspecting pixels

  • Fit or 0 fits the image while preserving its proportions.
  • 1:1 or 1 shows one image pixel per desktop logical pixel.
  • + and - zoom; Ctrl+mouse wheel also zooms.
  • Drag the canvas or use arrow keys to pan. The mouse wheel pans vertically; Shift+wheel pans horizontally.
  • Rotate or R rotates the view clockwise without changing the saved image.
  • The title-tab maximize button fills the usable desktop; click again to restore the previous window size.

The status strip shows source dimensions, encoded size, zoom and source path. Transparent pixels appear over a checkerboard. Enlarged pixels use nearest-neighbour scaling for inspection; source colours are preserved even when the desktop uses a monochrome theme.

Camera snapshots

Reload or Ctrl+R rereads the current file. Watch 2s checks it every two seconds and decodes only when it changes. A capture tool should write a complete PNG/JPEG/BMP to a temporary file, then rename it over the watched filename. Failed or incomplete reads keep the last good image and pause the watch. Reload after correcting the file, then enable Watch again. Closing stops the watch and discards the document.

This is a snapshot viewer, not a camera driver or video stream. Device VFS reads currently provide text values and the firmware download command can truncate large files. Direct device image download is therefore not offered. Save a complete snapshot on this computer using your acquisition tool first. No camera is started and no device setting is changed.

Limits and application integration

Encoded files are limited to 32 MiB and decoded images to 16 Mi pixels. Loading runs in background workers. Zoom caches only the visible canvas. Progressive JPEG, 16-bit PNG, GIF, SVG and raw sensor buffers are not currently decoded. EXIF orientation and colour profiles are not applied; use Rotate when needed. This viewer does not perform scientific image calibration or alter original files.

Native desktop controllers can submit a complete encoded snapshot with tiku_trk_image_window_bytes. It copies the producer's binary buffer before returning and decodes off the UI thread. Acquisition, transport, frame boundaries and camera-specific controls belong to the producer. This is a host controller API, not a device wire protocol.
