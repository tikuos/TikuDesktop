TikuMarker

TikuMarker reads Markdown files as formatted documents. Open it from Applications > TikuMarker, or double-click a .md or .markdown file in Tracker. Uppercase extensions work too. A saved Markdown association takes precedence; use Open With or Settings > File Associations… to choose another app. Plain .txt files open with Editor by default.

Open and read

Choose File > Open or press Ctrl+O. Ctrl+L selects the Location bar, where you can enter a complete local path or a filename in the current document's folder. TikuMarker starts with a welcome page; it does not reopen an old file automatically.

Headings, paragraphs, bold and italic text, lists, block quotes, fenced code blocks, tables, links and local images are supported. The renderer uses a Markdown subset: task checkboxes, reference links, footnotes, math and embedded HTML are not supported. Code fences preserve text but do not provide syntax highlighting.

Find your way

  • View > Outline: jump to a heading.
  • Ctrl+F: find text in the document. Enter and Shift+Enter step through matches; Escape hides the search bar.
  • Ctrl+D: add or remove a bookmark at the current position. View > Bookmarks opens the list. TikuMarker's bookmarks are saved separately from TikuReader and Help, with up to 32 entries.
  • Alt+Left / Alt+Right: go back or forward, keeping reading positions.
  • Edit > Search folder: search Markdown and HTML documents beside the current file and in subfolders. Results appear in the sidebar. You can keep reading or choose Edit > Stop Search to cancel.

Adjust the view

View > Larger Text and Smaller Text change document text without changing the desktop font. Ctrl+Plus and Ctrl+Minus do the same; Ctrl+0 restores the desktop size. Comfortable Reading Width centres a column up to 720 pixels wide. These settings apply to the current window.

Edit elsewhere, reload here

TikuMarker does not change the document. Use Tracker's Open With > Editor to edit the source, save it, then press Ctrl+R in TikuMarker. Reload keeps your reading position where possible. If the file cannot be read, the current document stays on screen and the status line explains why. Select text and press Ctrl+C to copy it, or use Edit > Copy code.

Local documents only

Local Markdown and HTML links work, including links to headings. Web addresses are not fetched. Scripts, forms and embedded programs are not run. Images must be inside the document's folder or its subfolders. Save files from a connected device to the computer before opening them.

The shared viewer accepts files up to 8 MiB, with up to 64 MiB of document tables. Files that exceed the budget are refused or show an explicit capacity notice. See Reader limits for image and folder-search bounds.
