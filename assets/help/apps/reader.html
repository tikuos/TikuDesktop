TikuReader

Read local Markdown and HTML documents in a dedicated desktop window. Launch it from Documents > TikuReader. Help remains a separate reader.

The compact toolbar provides Back, Forward, Reload, Open and Find icons. Hover an icon to see its name and shortcut. The address fits alongside the icons, or below them in a narrow window. The title-tab maximize button fills the available desktop; click it again to restore the previous size.

Opening documents

Choose Open or press Ctrl+O. Select a local .md, .markdown, .html or .htm file in the native file picker. Other file types and device endpoints are not opened. Copy device documents to the computer first.

The Location bar also opens local documents. Press Ctrl+L, type a complete path (or a filename in the current document's folder), then Enter or Go. Escape restores the current address. Filenames containing # or % are literal. For long addresses, use Open; editing then uses the filename within its folder.

The reader starts with a welcome page, not a previously opened document. During one desktop session, closing and reopening the reader retains its page.

Navigation and reading

Back and Forward retain reading positions. Alt+Left and Alt+Right do the same. Local links resolve relative to the displayed file, including parent directories and heading anchors. Web links and file URLs are not opened.

Find or Ctrl+F opens a search bar below the document. Escape or its close button hides the bar. Enter and Shift+Enter move between matches; Ctrl+G and Ctrl+Shift+G do the same. Search folder scans the current document's folder and subfolders when explicitly requested. It runs in the background, so you can keep reading. Results appear as each group of documents finishes; the status line reports progress. Choose Edit > Stop Search to cancel, or click Stop Search in the Find bar. Choosing Edit > Search folder during a search starts a new one for the words in the Find bar. Completed results remain available through View > Search Results, including after you open a result or switch to Outline. An incomplete search is identified in the status line rather than reported as a complete set of results.

View > Outline follows headings. View > Bookmarks remembers local filenames and reading positions across launches; Ctrl+D toggles a bookmark. Changes from separate Reader windows are combined. If another window is saving bookmarks at that moment, nothing changes and the status line asks you to try again. If bookmarks cannot be saved, for example because the settings folder is read-only, changes are kept in that window until it closes, and the status line says so. Select text and use Ctrl+C, or choose Edit > Copy code for an example without running it. The Edit menu also provides Copy link and Search folder.

Text size and reading width

Choose View > Larger Text or Smaller Text (Ctrl+Plus and Ctrl+Minus) to change this window's document text. The available sizes are 10, 12, 14 and 16 pixels. Default Text Size (Ctrl+0) follows the desktop font setting again. Toolbar text and other applications are unchanged.

View > Comfortable Reading Width centres a column no wider than 720 pixels in a wide window. Choose it again to use the full width. Text size and reading width apply to this Reader window and are not saved across launches.

Changes on disk

Reload or Ctrl+R reads the latest saved version without adding a history entry. If the file is missing or unreadable, the current display is kept.

Supported documents and safety

This is an offline, read-only document reader, not a web browser. It uses the same bounded HTML and Markdown dialect as Help. Scripts, forms, external stylesheets and network requests are not executed. Images are allowed only inside the displayed document's directory or its subdirectories.

Files up to 8 MiB are read completely, using document-sized memory buffers. Larger, binary or over-budget files are refused and the current page is kept. Renderer tables grow when you narrow the window or enlarge the text, within a 64 MiB budget per document. A capacity notice appears when the layout needs more than that budget or than memory allows, or when a document nests elements more than 16 levels deep. Folder search examines at most 128 documents, four directory levels, 8,192 directory entries and 32 MiB of source text. Bookmarks are limited to 32 and are separate from Help bookmarks.

Images are decoded when they are first drawn. The reader keeps at most 16 MiB of decoded pixels and decodes an older image again when you scroll back to it. A page's image records have a separate 1 MiB budget. Each image must be at most 4 MiB on disk, no wider or taller than 2,048 pixels, and no larger than 1,048,576 pixels in total. Reload the document to retry an image that was missing or could not be decoded.
