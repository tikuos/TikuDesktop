Lire et rechercher

Ctrl+F active la recherche dans la page. Entrée passe au résultat suivant ; Maj+Entrée revient au précédent. Toute l'aide recherche dans les pages et affiche des extraits. Tab parcourt les liens et Entrée ouvre le lien sélectionné. Retour arrière revient à la page précédente.

Sélectionnez du texte puis utilisez Ctrl+C pour le copier. Le bouton Code copie un exemple sans les balises HTML. Plan affiche les titres ; le bouton + ajoute ou retire un signet. F1 ouvre l'aide contextuelle.
