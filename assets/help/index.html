TikuDesktop Help

These pages are read from the help folder beside the program, and can be written in Markdown or a small dialect of HTML: headings, paragraphs, lists, tables, code, quotations and links. There is no network behind them, so a page is only ever a file of this folder.

The pages

  • Windows and files: folder windows, the three views, selection, renaming, the Trash and Get Info
  • The Deskbar: the bar, its leaf menu, the application groups, the clock and the window rows
  • Finding things: the Find window, saved searches and the Select window
  • Settings: the preferences windows the leaf's Settings row opens
  • Devices: connecting a board, the Device Monitor and the VFS Inspector
  • The keyboard: every chord, written out, since a menu draws only the letter
  • Markdown pages: formatting, code examples, tables, links and supported syntax

The programs

An application that names a page of its own puts a Help row in the Tiku menu while one of its windows is in front.

  • Developer Calculator
  • TikuHex binary editor
  • Editor
  • Terminal
  • TikuBasic and TikuC
  • TikuBench and TikuConsole

  • TikuImage: images and camera snapshots

Reading with the keyboard

Ctrl+F focuses Find in page. Enter and Shift+Enter find the next and previous match; Ctrl+G and Ctrl+Shift+G repeat the search. Matches are highlighted, including phrases split by bold or other inline markup. Use Search all help for a list of matching pages and short excerpts.

Drag across text and press Ctrl+C to copy it. Ctrl+A selects the whole page when the page has keyboard focus. Copy code copies the selected code block, or the first visible block, without HTML markup. Oversized selections are refused rather than silently cut.

Outline shows the page's headings. + adds or removes a bookmark at the reading position, and Bookmarks lists saved places. Both lists support the keyboard and independent scrolling. Resizing and font changes preserve the paragraph being read.

F1 opens help for the current application or preferences window. TikuBench's View / Results report opens a readable snapshot using this same window; viewing a report does not run tests.

The page itself takes the keyboard when the window opens, so a reader who never reaches for the mouse can still walk it.

  • Tab and Shift+Tab step from link to link, and the link that will be followed is ringed
  • Return follows it
  • Backspace comes back to the page it was read from, and the place in it that was being read
  • Page Up and Page Down move a screen at a time, Home and End reach the ends of the page
  • Ctrl+W closes the window

Where a link goes

A name beginning with # is a place in the page now shown. A file name is another page of this folder, and one that climbs out of it with .. is refused. A path beginning with / is a place on this machine, and is opened in a window of its own rather than read here.

A web address is not followed. Hovering a link previews its destination; select a link with Tab and choose Copy link to copy the address. The reader says so in its own line rather than doing nothing, because a link that looks followed and did nothing is worse than one that is refused out loud.

Written for the desktop and read by it. The folder these pages come from can be named outright with the TIKU_HELP variable, which is how a copy under development is read instead of the installed one.

Local PNG, BMP and baseline JPEG images can appear in pages. Images are scaled to fit the page and unavailable images retain their alternative text. Remote images are never fetched. Translations can be placed under language folders such as help/fr/; missing translated pages fall back individually to the main help folder.
