Settings

The Deskbar leaf's Settings row opens a submenu of eight preference windows, in this order: Deskbar preferences…, TikuTracker preferences…, TikuDesktop preferences…, Fonts…, Sounds…, Devices Preferences…, Startup Preferences… and File Associations…. The row below them shows or hides replicants and opens no window. Back to the contents.

Deskbar preferences

Eight rows are tick boxes: Sort applications by name, TikuTracker always first, Show application expander, Expand new applications, Hide application names, Always on top, Auto-raise and Auto-hide. Five rows carry a minus and a plus instead: Icon size steps by 8 px between 16 and 96, Font size by 2 px between 10 and 16, and Recent documents, Recent folders and Recent applications each have a tick box of their own and a count from 0 to 50.

Three rows grey out when they do not apply. Show application expander and Expand new applications work only while the bar is docked left expanded or right expanded, and Auto-raise only while Always on top is off.

The box beside Dock location shows the number of the dock the bar is in now, and a click in it moves the bar: the left third gives the left mini dock, or the left expanded dock in its middle band, the right third the two right docks the same way, and the middle column the top dock above and the bottom dock below. The keys reach the same six: 8 or Up, 2 or Down, 7 or Home, 9 or PageUp, 1 or End, 3 or PageDown.

Every change reaches the bar and is written at once, so there is no Done button. Defaults puts back the built-in settings and Revert what the window opened with; each is greyed when it has nothing to do. Edit in TikuTracker… opens the Deskbar's own folder, ~/.config/deskbar, in a file-manager window.

TikuTracker preferences

Four page names run down the left: Desktop, Windows, Volume icons and Disk mount. Click one to show its settings. A page name is drawn heavier while that page holds a change made since the window opened. Settings carry the names they have in the settings file:

  • Desktop: ShowDisksIcon, MountVolumesOntoDesktop, MountSharedVolumesOntoDesktop, IntegrateNonBootBeOSDesktops, SelectedLabelColor
  • Windows: ShowFullPathInTitleBar, SingleWindowBrowse, ShowNavigator, TransparentSelection, SortFolderNamesFirst, HideDotFiles, TypeAheadFiltering, GenerateImageThumbnails, DarkMode, GlobalMenuBar
  • Volume icons: ShowVolumeSpaceBar, UsedSpaceColor, FreeSpaceColor, WarningSpaceColor
  • Disk mount: EjectWhenUnmounting, AutoMount

A tick box turns its setting on or off. A colour swatch is the control for a colour, and a click steps to the next colour of a list of twelve. DarkMode has three positions rather than two, light, dark and without hue. MountSharedVolumesOntoDesktop is greyed while MountVolumesOntoDesktop is off, and a click on it is refused. Each change is written to ~/.config/TrackerSettings as it is made. Revert acts on all four pages at once, not only on the one showing. Defaults acts on the first three; Disk mount is never put back to a default.

TikuDesktop preferences

This window sets the picture behind the Desktop and the size of the icons on it. The six-row list begins with No picture; the rest are the picture files in the Desktop folder and in the wallpapers folder beside it, read each time the window opens. While neither folder holds one the list says Drop a picture in the Desktop to offer it here.

Under How it is laid are At its own corner, Centred, Scaled to fit and Tiled; they take a click only while a picture is showing. The Icon size minus and plus step through 32, 40, 48, 64, 96 and 128 px, and the ends stop rather than wrap. Every choice reaches the Desktop and is written at once, and Defaults and Revert work as they do in the Deskbar window.

Fonts

The Family list offers the faces the toolkit carries, then any TrueType families found in ~/.config/tracker/fonts. That folder is read each time the window opens, so a face dropped in while it was shut is offered when it opens again. Size steps by 2 px between 10 and 16, and Preview shows both weights of what is chosen. A line in the window says that changes apply immediately and that Revert restores the settings the window opened with. Done closes it. The size here is the one the Deskbar window's Font size row changes.

The middle button says Built-in or the name of a file. Pressing it steps to the next file in ~/.config/tracker/sounds and plays it, and back to Built-in after the last one; only .wav and .score files are offered, and the button is greyed while the folder holds none. The ... button opens a file panel at the home folder, and the file chosen there is copied into the sounds folder and played. Test plays a row even when its moment is turned off. Volume is a slider from 0 to 100 percent whose knob follows the pointer and is written when it is let go. Defaults and Revert cover the moments, their files and the volume together.

Devices Preferences

This window reads and changes settings on a connected board, so connect one from the Devices menu first; see Devices. The list down the left is the boards now mounted, and under the chosen board its sections, each with its icon: Identity, Processor, Memory, Storage, Power, Radio, Security and Boot, the way a system report lists them. Choose a section and the right side shows it: the board's name over what it said it is, the part and the firmware, then the section's rows under its heading. A section the board has nothing for, a radio on a part without one, is greyed out in the list and cannot be chosen; until the board has been read, every section is offered.

Each row is a label and a value. A row with a chevron at its right end is a setting: choose it and the group underneath edits it. The other rows are facts the device reports, such as the MCU, the firmware, the uptime, the memory used, the stack's room and the reason for the last reset; choose one and the group explains it. Under Memory and Storage the rows with a colour swatch are the estates each memory is carved into, from the device's own maps: static data, the stack pool, the tier arena, the code window, the module slot, the store and the persist home, each with its size and what is in use. Choose one and the group draws the whole memory as a bar with that estate outlined. Most are decided by the firmware's linker and cannot be changed from here. The one that can, on firmware with the layout service, is the NVM tier under Storage: type its size in kilobytes, within the floor, the ceiling and the step the help line quotes, and Save for restart stages it. The device applies it at its next restart, and the store moves with the tier. When the store holds files the window asks first, because staging the move erases /data; Erase and stage confirms it. While a change is staged the row says both sizes, the heading wears a pill, and the button becomes Cancel staged. After the restart the help line says whether the staged change applied, and why not when it did not. When the device holds its store, as it does after a firmware update it cannot vouch for, the heading says store held, the row is read-only, and the help names what gives the store back in the device's shell: a restart, layout recover with the store's offset, layout resume, or mkfs, by the device's reason. The two switches, External PSRAM and eMMC card, appear on a board that has the hardware, Up bringing it online and Down powering it off. Counts of bytes and spans of time are shown as a person reads them. The window opens on Processor with CPU clock chosen, grows by its bottom-right corner so a section shows more rows, and with nothing connected it says No devices connected.

Startup Preferences

Under Windows are Reopen my previous folders, which restores the folders of the last session, and Open default folders if none reopen. Turn both off to start with no folder windows. Under Open these applications is the list of installed applications, six rows at a time, with < and > to page through it; the line beneath counts the applications ticked across every page.

Open nothing clears both folder boxes and every application box. Save writes the choices, Cancel discards them, Ctrl+S saves and Ctrl+W closes without saving. Changes take effect the next time you start TikuDesktop, and saving never starts or closes an application now. An application the saved list does not name starts only if it was installed as a trusted one. The list holds 32 applications, and a save that would pass that says so instead of dropping choices. Safe mode skips the saved folders and the applications; the default-folder box still applies.

File Associations

Choose Settings → File Associations… to set which application opens a document. Select a file type in the left list, then its default application in Opens with. The lists come from the registered file types and applications; only applications declaring support for the type are offered. For example, BASIC source can open in TikuBasic or Editor. Use the arrow buttons for additional pages.

Automatic removes your override for the selected type and shows which application would be used. The familiar TikuImage, TikuBasic and Editor associations are starting defaults, not fixed rules. Types group equivalent extensions: JPG and JPEG share a setting, as do the plain-text TXT and MD files. Uppercase extensions follow the same setting.

Choose Save or Ctrl+S to apply the edited choices to future opens, including double-click and Open With in Tracker. No restart is needed. Cancel, Escape or closing the window discards unsaved choices. Tab and Space navigate and select controls. Saving preferences does not launch applications, run source code or change open documents.

A saved application that is temporarily unavailable is identified in the panel; automatic selection is used until it returns. Your preference is kept unless you choose another app or Automatic.
