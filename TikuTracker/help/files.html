Windows and files

A folder opens in a window of its own, and opening the same folder again brings that window forward instead of making a second one. The window is titled with the folder's own name, or with its whole path when ShowFullPathInTitleBar is set on the Windows page of TikuTracker preferences; with SingleWindowBrowse set, one window changes place rather than a new one opening. A strip along the bottom counts what is there: empty folder, N items, or N/M selected.

The three views

The Window menu offers Icon view, Mini icon view and List view, and marks the one in force. Ctrl+1, Ctrl+2 and Ctrl+3 switch between them. The Icon view row carries a submenu of sizes from 32 x 32 to 128 x 128.

List view draws a strip of column titles and adds an Attributes menu to the menu bar; both go when the view changes. Clicking a title sorts by that column, and clicking the sorted column again reverses it. Shift and a click set the tie-break, or swap it with the key when the sorted column is clicked. A title dragged sideways moves its column, and the band at its right edge resizes it.

Choosing, opening, renaming

A plain click picks one entry; a click on empty space clears the selection. Ctrl and a click add or remove one entry. Shift and a click take the range from the last anchor. Ctrl+Shift and a click give the whole range the state the clicked entry does not have. Typing letters jumps to the best match by name.

A double click on a folder opens it in its own window; on anything else it hands the item to the application that opens its type. Holding Alt over either closes the window it came from. A double click inside the Location column opens the folder that column names. A link whose target is gone opens nothing and says so.

Ctrl+E opens an editor on the selected name, in place. Return commits it and Escape abandons it; a name the filesystem refuses keeps the editor open with the text selected whole for retyping. Tab commits and walks on, to the Value column of the same entry when there is one to edit and otherwise to the next name; Shift+Tab walks back. Entries of the device namespace cannot be renamed, and the walk skips them.

The File and Window menus

A folder window carries two menus, File and Window. In list view a third, Attributes, is added after Window.

File holds Find…, then New folder (a New submenu, with Templates inside it, once the Templates folder holds anything), then Open, Edit query, Open with, Get info, Edit name, Duplicate and Move to Trash, then Move to, Copy to and Create link, then Cut, Copy and Paste, then Identify, and last an Add-ons submenu. In the Trash, Delete and Restore stand where Duplicate and Move to Trash would, and Empty Trash leads the menu.

Window holds the three view modes, then Resize to fit, an Arrange by submenu (Name, Kind, Size, Value, Capability, then Reverse order, then Clean up), then Select…, Select all, Invert selection, Open parent, Close, Close all in workspace, and Preferences….

Attributes is a row per column: Name, which is always on and cannot be turned off, then Kind, Value, Size, Capability, Modified, Location, Permissions and Original path, then Copy layout and Paste layout.

Nine commands change under Shift

Drag and drop

Dragging entries onto a folder is TikuDesktop's. The single-window TikuTracker has no drop-onto-a-folder handling at all: a drag there ends by putting icons down where they were dropped.

What a drop does is read when the button comes up, not when the drag began. Within one filesystem a drop moves; across two it copies. Holding Alt copies in either case, and copies onto the folder the items already sit in. Holding Ctrl makes links instead, and adding Shift makes them relative. A secondary click that ends the drag asks first, with Move here, Copy here, Create link here and Cancel; an unwritable destination greys the first three, an unwritable source greys only Move here.

The Trash

Del moves the selection to the Trash, and Shift+Del deletes outright, as plain Del does inside the Trash. There is a Trash per filesystem, which is what keeps moving something into it a rename rather than a copy, and a Trash window shows the union of them all. A device namespace has no Trash: its nodes are not files, so a delete there happens outright, with no question about the Trash. Restore puts a trashed item back where it came from, making any missing folders on the way, and does not overwrite something that has since taken the original name. A whole volume dragged onto the Trash is unmounted rather than deleted.

Get Info

Get info opens one window per item, titled with the item's name and the word info, cascaded so several stay legible. Its tabs are Information, Permissions and Attributes.

Information lists the size, or the capacity for a volume, then Created, Modified, Kind and Location, and then whichever of Link to, Opens with, Filesystem and Dimensions apply. Clicking the Opens with row steps to the next application that handles the type and records that choice. Permissions is three boxes, Read, Write and Execute; where the store serving the item cannot set them the boxes are greyed and the window says This item's permissions are not yours to set. Clicking the name opens an editor on it. A double click on the icon at the top opens the item, a drag from it carries the item, and a drop onto it puts what was dragged into that folder.

Open with

Installed defaults include TikuImage for PNG, JPEG and BMP images, TikuBasic for .bas source and .tiku project descriptions, and Editor for .txt documents. Uppercase extensions work as well. Opening BASIC source edits it; it does not run the program. Your explicitly preferred handler takes precedence. Change these defaults in Settings → File Associations…; see File Associations preferences.

The File menu's Open with row is a submenu of the applications that claim the selection's types, best match first, each saying how it matches: opens this type, opens this kind of file or opens anything, with the preferred one marked. Its last row, Open with…, opens a window of the same name listing ten at a time, with Open and Open and make preferred beneath it. Choosing an application that does not claim the type asks first, offering Cancel and Open; Escape answers Cancel.

The Select window

Select… opens a small window titled Select. There is one of it, aimed each time at the window it was opened from. Ctrl+Shift+A centres it on the pointer; the menu row opens it in a fixed place. It is headed Select items whose name: a text field, a rule, and the boxes Ignore case and Invert selection. The rules are starts with, ends with, contains, matches wildcard expression and matches regular expression. It starts out on the wildcard rule with Ignore case ticked, so a typed name with no wildcards in it is an exact match that ignores case, and it keeps whatever was last chosen.

The Select button applies the pattern to the window it was opened from, then closes. It picks entries out rather than hiding the rest, and reports how many it found. An expression the matcher will not take selects nothing and says why.
