TikuDesktop Help

These pages are read from the help folder beside the program, and are written in a small dialect of HTML: headings, paragraphs, lists, code, quotations and links. There is no network behind them, so a page is only ever a file of this folder.

The pages

  • Devices: connecting a board, the Device Monitor and the VFS Inspector

Reading with the keyboard

The page itself takes the keyboard when the window opens, so a reader who never reaches for the mouse can still walk it.

  • Tab and Shift+Tab step from link to link, and the link that will be followed is ringed
  • Return follows it
  • Backspace comes back to the page it was read from, and the place in it that was being read
  • Page Up and Page Down move a screen at a time, Home and End reach the ends of the page
  • Ctrl+W closes the window

Where a link goes

A name beginning with # is a place in the page now shown. A file name is another page of this folder, and one that climbs out of it with .. is refused. A path beginning with / is a place on this machine, and is opened in a window of its own rather than read here.

A web address is not followed. The reader says so in its own line rather than doing nothing, because a link that looks followed and did nothing is worse than one that is refused out loud.

Written for the desktop and read by it. The folder these pages come from can be named outright with the TIKU_HELP variable, which is how a copy under development is read instead of the installed one.
