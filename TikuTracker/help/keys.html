The keyboard

A menu draws only the letter of a command's key, with a leading ^ when Shift is part of the chord. It never draws the modifier. The Find row reads F and the Select row reads ^A, so this page is where the whole chord is written down.

The command modifier is Ctrl. An add-on is reached with Ctrl+Alt. Move to Trash is the one command bound with no modifier at all: plain Del.

Most of these keys act on the folder window in front, so they need one. Del is the exception: with no window focused it acts on the desktop's own selection. What the commands do is on Windows and files, and the list of pages is on Contents.

The desktop

KeyWhat it does
MenuOpens the Deskbar's leaf menu, and closes it again. It is the one way to the Deskbar without the pointer.
Ctrl+,Opens TikuTracker preferences. No window need be focused.
Ctrl+TabOpens the Switcher; Ctrl+Shift+Tab opens it walking backwards.
Ctrl+Alt+KOpens Force Quit, which stops a connected application and every window it owns. See Force Quit.
Ctrl+Alt+OThe Open in Tracker add-on.
Ctrl+Alt+EThe Open with Editor add-on.
Ctrl+Alt+IThe Inspect add-on.

Those three are the add-ons the desktop registers itself. One of your own, from ~/.config/tracker/add-ons, takes the same Ctrl+Alt and the letter it was given; the letters are rebound in ~/.config/tracker/addon-shortcuts.
