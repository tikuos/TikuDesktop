Editor

A native text editor for notes, configuration files, logs and source text. Open it from Applications → Editor, or double-click a local text file in Tracker. Each document launch opens a separate editor. An ordinary launch starts empty; it never restores an unrelated project.

Opening and navigating

File → New starts an empty document; Open… uses the desktop's file panel. Failed loads leave the current document untouched. BASIC and C files receive syntax colouring based on their extension.

Resize or maximize the window to fit your work. Click to place the caret, drag to select, or hold Shift while clicking or pressing navigation keys. The mouse wheel scrolls vertically; Shift+wheel scrolls horizontally. Both scrollbars have end arrows, draggable thumbs and clickable page tracks. View → Line Numbers toggles the gutter. Tabs display at four-column stops; Show Invisibles marks spaces and tabs without changing file contents.

The Pe-inspired toolbar has small New, Open, Save, Undo, Redo and Find icons, followed by the filename and an unsaved-change star. Hover over an icon to see its action and shortcut in the bottom status pane. The caret's line and byte column sit beside the horizontal scrollbar. Encoding, line endings and temporary messages share this bottom edge, leaving the document uncluttered.

Editing tools

The Edit menu offers Undo, Redo, Cut, Copy, Paste and Select All. Clipboard text is shared with other desktop applications. In a search field, these commands act on that field rather than on the document. In the document, pastes and replacements are single undo operations. Undoing back to the last save clears the modified star.

Search → Find… opens a separate Find and Replace window, without resizing or covering the text inside the editor. Search is literal. Match case and Whole words control matching; case-insensitive matching folds ASCII letters. Next and Previous wrap through the document; matches are selected in place. Replace changes only a selected match, then finds the next one. If the selection is not a match, Replace first finds one without changing unrelated text. Press Enter in Find to find the next match, Shift+Enter for the previous match, or Enter in Replace to replace one. Tab changes fields and Escape closes the Find window. Click the document to resume editing without closing Find. Replace All changes every matching occurrence in this document as a single undoable operation.

Go to Line… accepts a line number; Return navigates there and Escape cancels. Regular expressions, multi-file search and soft wrapping are not yet provided.

Saving safely

Save writes to the current file. For an unnamed document it opens Save As automatically. Save As… writes to a chosen path and changes the document's name only after success. Empty files, UTF-8 BOMs, tabs, LF/CRLF endings, and the presence or absence of a final newline are preserved.

A save writes and flushes a temporary file in the same directory before replacing the destination. Failed writes keep the existing file and leave the document modified. Permission bits of an existing file are retained. If the original has changed or disappeared on disk, Save refuses to overwrite it: reopen the disk version or save your edits under another name. Read-only files, symbolic links and hard-linked destinations require Save As to another regular file.

Unsaved work

New, Open, Revert and Close ask before discarding unsaved edits. The choices are Cancel, Discard and Save; Return and Escape both choose the safe Cancel by default. A failed save does not continue the requested action. If you make further edits while an Open panel is outstanding, its result cannot replace those edits.

A title-bar close of a modified document reopens its window with the same question because the window host has already removed the original frame. If the application is stopped gracefully with unsaved edits, it attempts to write a private /tmp/TikuEdit-recovery-XXXXXX copy and prints its path to the launch terminal. Open that file manually to recover the text. This is not periodic autosave: a process crash, Force Quit or power loss may prevent recovery. Temporary copies may be removed by the operating system.

Keyboard shortcuts

  • Ctrl+N / Ctrl+O: New / Open.
  • Ctrl+S / Ctrl+Shift+S: Save / Save As.
  • Ctrl+Z / Ctrl+Shift+Z or Ctrl+Y: Undo / Redo.
  • Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+A: Cut / Copy / Paste / Select All.
  • Ctrl+F / Ctrl+H: Find / Replace.
  • Ctrl+] / Ctrl+[: Find next / previous.
  • Ctrl+G: Go to Line.
  • Home / End: start / end of line. Ctrl+Home / Ctrl+End: document start / end.
  • Page Up / Page Down: move a page. Shift extends the selection.
  • Ctrl+W / Ctrl+Q or Escape: Close, with an unsaved-change check.

Running BASIC text

View → Run (Ctrl+R) runs BASIC text with the local tiku-basic interpreter, not on a connected board. A named file must save successfully first; an unnamed document runs from a private temporary snapshot. Output appears in a separate pane below the text. Closing the editor terminates a run it still owns. Use TikuBasic for project development and board uploads.

Supported text and limits

Editor now uses dynamically allocated text lines and transactional undo. The old 31,999-byte, 4 MiB, 4,000-line and 1,023-byte-per-line limits are gone. Very long lines are drawn only across the visible viewport. Limits now come from allocation success and representable indexes (signed 32-bit coordinates; the loader rejects inputs larger than INT_MAX - 1 bytes). Allocation failures, binary data, invalid UTF-8, bare carriage returns or mixed LF/CRLF endings are reported without truncating the current document.

Undo retains at most 256 complete changes and targets 32 MiB of history, keeping at least the newest complete edit even when it alone exceeds that size. It does not require adjacent text lines to fit inside a temporary 1 KB buffer.

The desktop text clipboard holds at most 4,095 bytes. Oversized selections are not copied or cut. This is a separate desktop-wide clipboard constraint, not a document or line-size limit. UTF-8 codepoint navigation is supported; grapheme-cluster navigation, bidirectional layout and other encodings are not.
