# Compatibility entry point

The Makefile in this directory forwards to the repository's root build.
There is no separate Tracker source tree or local binary directory.

Tracker is in `system/tracker/`, the desktop in `system/desktop/`, and shared
file-manager code in `system/shared/`. Tests are in `tests/`, help and
translations in `assets/`, and documentation in `docs/`.

See the [repository README](../README.md) and
[layout guide](../docs/architecture/layout.md).
